# Mobile picture attachments for CAD jobs

The Android CAD Chat sends one gallery or camera picture with an ordinary `POST /remote/v1/agent/jobs` request. RemoteAgent validates the prompt and image envelope, then forwards it to AgentHost `POST /jobs/submit`. The Host validates actual PNG/JPEG bytes and persists them atomically with the job in `JobInputImages`. Both the initial planner call and later revision calls load the same image. The planner sends it as a Responses API `input_image` alongside the text request and clarifications. The resulting CAD plan still requires review and approval under the existing job rules.

The Host advertises `jobInputImages` in `/health` only when its active planning provider accepts images; RemoteAgent forwards it in `agent/status`. The deterministic simulation planner does not advertise or accept pictures. Android permits photo submission only when the field is true. Missing capability information from an older Windows installation fails closed for pictures while text-only jobs continue. The image route allows at most 4 MiB of decoded image data within a 6 MiB JSON envelope; other remote operations keep their existing smaller limits. Gallery/camera content is normalized to JPEG on the phone, removing source metadata.

An image starts in the normal CAD job workflow. If planning finds missing dimensions, the current job's clarification and revised-plan flow is used with the same image. Automatic promotion into the separate Design Brief session is not implemented. Preserve that separation until there is a reviewable migration of job identity, image ownership and approval state.

Automated tests cover route bounds, invalid-image rejection, atomic persistence/reopen, planner input and image reuse after a revision, Android payload construction and refusal when the workstation does not advertise support. The Android instrumentation APK compiles, but gallery/camera selection and the complete phone-to-Windows path still require a physical-device test. Do not label this feature native-SOLIDWORKS verified based on compilation or simulation.
