## Rulings

- Ruling: SOLIDWORKS 2020 SP0.0 supersedes the original 2018 assumption. Later SOLIDWORKS versions remain version-independent targets and require regression certification.
- Ruling: GitHub Actions may compile the bridge without SOLIDWORKS interop libraries. `SolidWorksSession` therefore has a compile-only no-interop path; actual COM behaviour is enabled only when the installed SOLIDWORKS interops are present.
- Ruling: integration tests are compiled in CI but are opt-in and must run on the user's SOLIDWORKS PC.
- Ruling: raw SOLIDWORKS COM objects must not escape the dedicated STA thread. `ISolidWorksSession.InvokeWithApplicationAsync<T>` is the only bridge boundary for command handlers so every COM call remains on the dispatcher thread.
- Ruling: the plan's approximate body-box verification is replaced by precise axis extreme-point measurement. SOLIDWORKS documents ordinary bounding-box values as approximate and unsuitable for comparison/calculation; V1's `GetBoundingBox` command will therefore calculate precise global XYZ extents using `IBody2.GetExtremePoint` for each solid body. This preserves the public command name while making the verification result suitable for tolerance checks.
- Ruling: do not use `IModelDocExtension.GetAdvancedSaveAsOptions` for V1 because it was introduced in SOLIDWORKS 2020 SP02 and the certified baseline is SP0.0. Save logic must use an API available at 2020 FCS/SP0, such as `IModelDocExtension.SaveAs`/`SaveAs2` where appropriate.
