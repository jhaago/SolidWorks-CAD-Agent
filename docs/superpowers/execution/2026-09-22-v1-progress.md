## Rulings

- Ruling: SOLIDWORKS 2020 SP0.0 supersedes the original 2018 assumption. Later SOLIDWORKS versions remain version-independent targets and require regression certification.
- Ruling: GitHub Actions may compile the bridge without SOLIDWORKS interop libraries. `SolidWorksSession` therefore has a compile-only no-interop path; actual COM behaviour is enabled only when the installed SOLIDWORKS interops are present.
- Ruling: integration tests are compiled in CI but are opt-in and must run on the user's SOLIDWORKS PC.
- Ruling: raw SOLIDWORKS COM objects must not escape the dedicated STA thread. `ISolidWorksSession.InvokeWithApplicationAsync<T>` is the only bridge boundary for command handlers so every COM call remains on the dispatcher thread.
- Ruling: the plan's approximate body-box verification is replaced by precise axis extreme-point measurement. SOLIDWORKS documents ordinary bounding-box values as approximate and unsuitable for comparison/calculation; V1's `GetBoundingBox` command therefore calculates precise global XYZ extents using `IBody2.GetExtremePoint` for each solid body. This preserves the public command name while making the verification result suitable for tolerance checks.
- Ruling: do not use `IModelDocExtension.GetAdvancedSaveAsOptions` for V1 because it was introduced in SOLIDWORKS 2020 SP02 and the certified baseline is SP0.0. Save logic uses the older `IModelDocExtension.SaveAs` path available at the baseline.
- Ruling: SavePart and OpenPart resolve paths through `WorkspacePolicy` before any COM invocation; CloseDocument closes only the active SOLIDWORKS document and does not terminate SOLIDWORKS itself.
- Ruling: job state transitions live only in `JobStateMachine`; invalid transitions do not mutate state or timestamps. Cancellation is allowed from every non-terminal state and terminal states cannot resume.
- Ruling: Auto mode may bypass the manual `Approved` state only for a validated, unambiguous plan. It never bypasses explicit overwrite authorization.

## Provider architecture amendment

- Cloud planning is provider-neutral behind `ICadPlanningProvider`.
- OpenAI is the first provider, using the Responses API with `store=false`.
- Deterministic, local, and manual planners can be added later without changing the job coordinator, CAD command contracts, or desktop client.
- API usage and cost metadata belong to the planning result and persisted job history; no provider credential may enter SQLite or logs.
