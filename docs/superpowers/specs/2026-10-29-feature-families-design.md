# Expand across CAD feature families

The user has authorized all useful upstream feature families, autonomous decisions and continued implementation. Retain the net48/SOLIDWORKS 2020 executor, approval, workspace, identity and recovery interfaces. Existing native features remain the baseline.

Use selective MIT ports in dependency order. Importing either entire server would introduce a competing COM owner, newer runtime/API dependencies and unverified tools. A source dump of unregistered handlers would not make features available to the AI. Native mutation, planner admission and independent verification must advance together.

This increment ports two useful COM-free upstream algorithms: linear/circular component placement and first/third-angle drawing-view layout. Register explicit planning-only bridge tools, so the functionality is callable now without modifying a document. These tools calculate predictions; they do not create assemblies/drawings, solve mates or certify rendered outlines. Do not extend the modelling planner allowlist until native adapters and verification exist.

Pattern inputs use mm, degree angles, column-vector row-major 3x3 rotations. Return expected generated placements excluding seeds and explicit SOLIDWORKS row-vector ArrayData with metre translations. Reject reflection, shear, scale, nonfinite values, ambiguous IDs, unknown parameters, duplicate full-turn placements and requests exceeding 256 total instances. Linear grids allow independent, nonparallel directions. Circular full-circle spacing omits a duplicate seed; partial spans include both ends.

Drawing inputs specify a 50..5000 mm sheet, positive model extents, unique standard views, projection, optional fixed scale, sheet scale and explicit usable rectangle. Reuse upstream standard view axes, grid cells, 15 mm gaps and standard scale selection. Default margins reserve space for a title block. Report fits=false when a fixed scale or the smallest standard scale cannot fit; never certify an actual title block or native view outline. Bound geometry and all results; explicit usable rectangles must lie inside the sheet. At most seven standard views.

Track the complete feature-family programme against the existing capability matrix, preserving the distinction between source availability, implemented calculations, registered execution, AI exposure and native acceptance. Optional specialist products remain conditional on installed modules/licences; arbitrary Python/VBA execution stays excluded.
