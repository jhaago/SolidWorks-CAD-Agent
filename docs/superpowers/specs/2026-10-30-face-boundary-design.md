# Exact face and outer-boundary inspection

Retain the existing native mutation gates. Add a working read-only `InspectFaceBoundary` bridge tool using the same `normalAxis` X/Y/Z and `side` Min/Max selector as the excluded face-feature drafts. Implement the reusable resolver underneath it; do not enable unfinished face-sketch/fillet/chamfer handlers.

Require one solid body, including hidden bodies. Enumerate planar faces, inspect outward normals and exact points using IFace2.GetClosestPointOn (five finite values: XYZUV). Use IBody2.GetExtremePoint in both axis directions for actual body bounds. Select the unique planar face whose outward normal matches the requested side and whose exact axis coordinate lies on that body extreme, within 0.00001 mm. Reject missing, tilted, split/coplanar, duplicate or malformed candidates; never pick by name, largest area, approximate face box or enumeration order. Normal alignment tolerance is 0.00000001 in cross-product magnitude.

Inspect all loops using IFace2.GetLoops (available since 2009), ILoop2.IsOuter and GetEdges (available since 2001Plus). Validate exactly one non-singular outer loop with 1..256 unique edges. Inner-loop edges must never enter the returned outer boundary. Reject singular/multiple/no outer loops, duplicate edge identities and incomplete arrays. Bound faces to 20000, loops to 4096 and total loop-edge visits to 20000. Persistent-reference hashes are inspection evidence only, not public mutation handles.

Separate pure face/loop decisions from a typed native adapter on the bound document's owning STA. Return face/outer-edge evidence, loop counts and explicit inspection-only flags. The operation must not select, rebuild or mutate geometry; verify dirty flag, active configuration, active sketch identity and selection count remain unchanged. Native code uses documented APIs predating 2020; no new runtime or API references.

Portable tests prove decision rules and malformed evidence handling. Existing isolated native fixtures test hidden/multiple solids and a through-hole plate, before/after save/reopen, when explicitly run on SOLIDWORKS 2020. Native-enabled compilation and runtime acceptance cannot be claimed from native-disabled CI. This is a concrete prerequisite for later face sketches and finishing, not their certification.

Compatibility addition after source inspection: a public Visiativ package labelled 2020 SP1 contains reference assemblies with version 28.1.0.74. Use only the two inspected DLLs as compile references; do not execute its install script, import it as a production dependency, or redistribute the package/binaries. Add a build target rejecting explicit missing references, major versions other than 28 and mismatched interop versions. CI may download the hash-pinned package into temporary storage for native-enabled compilation, with output isolated from the distributed native-disabled Windows bundle. Test the guard with synthetic metadata assemblies; such tests prove the guard, not real native API compatibility. Actual version-28 references separately prove compilation.
